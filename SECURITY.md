# Security policy

ClinicGuard is an educational security lab and must not receive real patient
data or production credentials.

To report a security issue, use a private GitHub security advisory for the
repository rather than opening a public issue with exploit details. Include
the affected file or service, reproduction steps, impact, and a suggested
mitigation.

For local demonstrations, rotate the default lab passwords, restrict exposed
ports, and destroy the stack after use with `make down`.
